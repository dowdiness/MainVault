## 💭 メモ
<!-- 思いついたことをすぐここに。後でTasksや別ノートに移動してもOK -->
  Title: Web Component interop: property binding and CustomEvent support

  Body:

  We're building a collaborative editor (https://github.com/dowdiness/crdt) with Rabbita, and need to embed custom
  elements like ProseMirror/CodeMirror inside Rabbita views. Currently this requires JS FFI workarounds for passing
  properties and listening to events.

  Two small changes would make this work natively:

  1. Make Attrs::property() public — it already exists as package-private in html/attrs.mbt and the VDOM diff engine
  handles it. Just needs fn → pub fn.

  2. Add Attrs::on_custom_event(name, handler) — sugar over .handler() that unwraps event.detail. The DOM primitives
  already exist in rabbita/dom/custom_event.mbt.

  These two together let Rabbita apps consume any web component without FFI boilerplate. Happy to send a PR.
