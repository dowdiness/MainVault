# PT契約 — 具体的な応募先と優先度

並走路線で必要なのは「週6–10時間 / 時給$60–80」の小さな案件。20–30件にコールド応募して2–3件決まれば成功。

## アウトリーチ戦略

**順序**:
1. 既存ネットワーク（高確率・即効性）
2. 国内スタートアップ DM（高確率・遅効性）
3. 海外スタートアップ DM（中確率・高単価）
4. プラットフォーム登録（低確率・低工数の保険）

## チャンネル別チェックリスト

### A. 既存ネットワーク（最優先・週内に着手）

ここが**並走路線で最も期待値が高い**。信頼ベースなのでハードルゼロ、時給交渉も容易。

- [ ] 過去の同僚で、現在スタートアップにいる人をリストアップ → 5名以上
- [ ] 関西PL/コンパイラ系コミュニティ（京大 / KMC / 関西Rubyist / etc.）の知人に DM
- [ ] X で過去にやり取りしたエンジニアにDMで近況打診

**テンプレート (DM)**:

```
お久しぶりです。最近フルタイム勤務から個人開発中心の働き方に切り替えていて、
週10時間くらいのスポット契約を1–2件探しています。

React/TypeScript中心、フルスタックOK、得意分野はフロントの基盤整備や
コンパイラ/型関連のツール開発です。

もし御社で「フルタイムは要らないけど誰か手伝ってほしい」みたいなのが
あれば、あるいはそういう話を聞いたら、ぜひ教えてください！
```

### B. 国内スタートアップへの直接DM

ターゲット軸:
- 開発者ツール / DevOps系
- AI / LLM系（フロント弱いところが多い）
- 京都 / 大阪 拠点（時差なし）

調査リスト用テンプレ:

```
[会社名]
- URL:
- 採用ページ:
- 連絡先:
- 接点（ある場合）:
- なぜ刺さりそうか:
```

調査対象の探し方:
- [日本のスタートアップDB](https://japan-dev.com/companies)
- [Wantedly](https://www.wantedly.com/) で「業務委託」「副業」フィルタ
- [YOUTRUST](https://youtrust.jp/) の業務委託募集
- ZennでReact/TypeScript記事を多く書いている会社の中の人

### C. 海外スタートアップDM（高単価）

ターゲット軸:
- YC バッチW24/S24/W25/S25 のスタートアップ
- Solo Founder / Tiny Team で React/Next.js を使っている所
- アジア時差OK明記がある所

**送信テンプレ**（`income-plan-2026.md` の応募テンプレD を参照、`~10 hrs/week` を必ず明記）

ターゲット調査用:
- [Y Combinator Work at a Startup](https://www.workatastartup.com/)
- [Hacker News "Who is hiring?"](https://news.ycombinator.com/submitted?id=whoishiring)
- Twitter/X で「hiring contractors」「looking for React engineer」検索

### D. プラットフォーム登録（保険）

- [ ] Toptal — スクリーニング2–4週、合格すれば時給$80+案件多
- [ ] Arc.dev — Toptalより敷居低、案件数多
- [ ] Lemon.io — 欧州系スタートアップが多い
- [ ] Wantedly — 国内、業務委託フィルタ可
