# B-1 製品スペック: TaPL入門以前 — 型システム入門を読むための入門書

## 一行コンセプト

「『型システム入門』(TaPL)を挫折した人 / これから読もうとしている人のための、TaPLを読むための前提知識を最短で揃える解説書」

## なぜこれが売れる仮説

1. **TaPLは日本のPL界隈で「読みたいが難しい」と語られ続けている本**。母集団は確実に存在し、Twitter/Zennで定期的に「TaPL読書会」が立つ
2. 既存の対抗書は「型システム入門」自体しかなく、入門以前の本は日本語で存在しない
3. 石本さんは既に [tapl-rescript](https://github.com/dowdiness/tapl-rescript) を持ち、Quartzサイトに関連ノートが多数 → 信頼性の地盤がある
4. 「数学嫌いを克服して読めるようになった視点」は実体験ベースで書ける → コピーされにくい

## ターゲット読者

- メインターゲット: 「TaPLを買ったが第1章で止まっている / 集合論や論理の表記でつまずいた」エンジニア
- セカンダリ: 「型理論に興味あるが、何から始めればいいか分からない」学生・若手エンジニア

