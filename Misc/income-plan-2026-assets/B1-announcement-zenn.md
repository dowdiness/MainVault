## TaPL、難しすぎませんか

『型システム入門 プログラミング言語と型の理論』(通称 TaPL) を買って、第1章で止まっている人。

正直に告白します。**私もそうでした**。

何の準備もなしに読もうとすると、集合論の表記、推論規則の横棒、帰納法の3種類が混ざった証明、そのどれもが「日本語ではあるが宇宙語のように見える」状態になります。

挫折します。本棚の肥やしになります。

でも、その本に書かれていることは本当に面白い。型システムがプログラムの安全性をどう保証するのか、なぜ Haskell や Rust の型推論があんなに上手く動くのか — TaPL を読み解ければ、それらの理論的な土台が見えてきます。

## ないなら作ろうと思いました

「TaPL を読むための入門書」が、日本語ではまだ存在していません。

数学書を読み慣れていない人向けに、TaPL に出てくる **数学のことば** と **証明の作法** だけに絞った薄い本があれば、何人もの挫折者を救えるはずです。

そこで自分で書くことにしました。

第1部だけでも、TaPL の第1〜3章を読み進めるための準備としては十分なボリュームになる予定です。

## 第1章のサンプル（冒頭抜粋）

```
TaPL の最初の数学的なつまずきは、たいていここで起きます。

  「Σ を有限の集合とし、写像 R : Σ → Σ を考える」

何が書いてあるか分かりますか？

これは、「Σ を入力にすると Σ の何かを返す関数 R を考えましょう」と
言っているだけです。ただ、数学の表記に慣れていない人にとっては、
矢印が何を意味しているのか、Σ という記号が「ある特定のもの」なのか
「何でもいいから一つ」なのか、ぱっと見では分からない。

この章では、TaPL に登場する集合と関数の表記を、
プログラマーが慣れ親しんでいる「型」と「関数の型シグネチャ」と
対応させながら読み解きます。
```
